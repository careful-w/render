## 二、整体架构

### 2.1 两遍渲染流水线

```
第 1 遍（累积遍）                       第 2 遍（显示遍）
┌──────────────────────┐              ┌──────────────────────┐
│ 绑定 accumFBO         │              │ 绑定默认帧缓冲         │
│ raytracer.frag        │              │ composite.frag       │
│ 每像素 1 条新采样光线  │              │ 累积和 ÷ 帧数 = 平均   │
│ glBlendFunc(ONE, ONE) │── 累加 ──▶  │ ACES 色调映射 + Gamma  │
│ HDR 采样写入 accumTex │              │ 输出到屏幕             │
└──────────────────────┘              └──────────────────────┘
```

### 2.2 渐进式累积 —— 实时性的关键

每帧每个像素只投 **1 条**采样光线（1 spp），画面有噪点但完全实时；
结果以浮点纹理累加，显示时除以帧数取平均：

```
第 1 帧：色₁/1         ← 全是噪点
第 10 帧：(Σ色)/10     ← 明显收敛
第 200 帧：(Σ色)/200   ← 接近干净光追图
```

> 蒙特卡洛积分的误差与 1/√N 成正比 → 采样越多越干净。
> 相机一动就清空累积重新收敛，这是所有"实时光追预览器"的标准做法。

## 三、光线追踪核心概念

### 3.1 相机光线生成

```glsl
// NDC 坐标 + 亚像素抖动（抗锯齿）
vec2 jitter = vec2(rnd(), rnd()) - 0.5;
// 除以 res.y 统一纵横比：x 方向天然带出 aspect，勿再乘
vec2 ndc = (2.0 * (gl_FragCoord.xy + jitter) - uResolution) / uResolution.y;

// lookAt 基向量
vec3 forward = normalize(uCamTarget - uCamPos);
vec3 right   = normalize(cross(forward, vec3(0,1,0)));
vec3 up      = cross(right, forward);

// 最终光线方向
dir = normalize(forward + ndc.x * tan(fov/2) * right
                        + ndc.y * tan(fov/2) * up);
```

### 3.2 光线-球体求交

解二次方程 |o + t·d − c|² = r²：

```
a = d·d
b = 2·(o−c)·d
c = (o−c)·(o−c) − r²
判别式 b²−4ac < 0 → 无交点
t = (−b − √disc) / 2a   （取较近的根）
```

- 地面用**超大球体**（中心 (0,−1000,0)，半径 1000）模拟平面
- 交点沿法线偏移 `EPS=1e-3`，防止光线与自身起点所在的表面重复相交（自相交黑斑）

### 3.3 漫反射（余弦加权采样）

```glsl
// n + 单位球面随机向量 = 余弦加权半球分布（重要性采样）
vec3 dir = normalize(h.n + randomUnitVector());
atten = albedo;  // 能量衰减 = 反照率
```

### 3.4 金属反射

```glsl
reflected = reflect(rd, n) = rd − 2·(rd·n)·n
scattered = normalize(reflected + fuzz * randomUnitVector()); // fuzz 磨砂感
if (dot(scattered, n) <= 0) return 吸收;  // 反射进表面内部 → 能量丢失
atten = 金属颜色;  // 反射率 = 颜色，能量守恒
```

### 3.5 玻璃折射 + 菲涅尔反射

```glsl
// 斯涅尔定律的向量形式
rOutPerp = ri * (rd + cosθ * n)          // ri = n1/n2
rOutPar  = −sqrt(1 − |rOutPerp|²) * n
refracted = rOutPerp + rOutPar

// 全内反射：sinθ > n2/n1 时折射不存在，只能反射
cannotRefract = ri * sinθ > 1.0

// Schlick 菲涅尔近似：入射角越大反射越强
R = R0 + (1−R0)·(1−cosθ)⁵，R0 = ((1−ri)/(1+ri))²
```

折射和反射**按菲涅尔概率二选一**（蒙特卡洛抽样），玻璃球表面随视角
呈现"正面透明、边缘镜面"的真实效果。

### 3.6 太阳面积光 → NEE 直接光采样

```glsl
// 漫反射散射：50% 概率直接朝太阳盘采样（阴影光线）
if (rnd() < 0.5) {
    vec3 d = sunDiskDir();          // 太阳盘上随机点（±5°）
    scattered = Ray(h.p, d, true);  // shadow 标志：阴影测试光线
    atten = alb * (2.0 * cosT / PI); // BRDF ρ/π·cos ÷0.5 分支概率
}
```

```glsl
// radiance 循环中：阴影光线命中天空 = 太阳直接光未被遮挡
if (r.shadow) color += throughput * SUN_IRRADIANCE;
else          color += throughput * skyColor(r.d);
if (r.shadow) break;  // 撞到物体 = 被遮挡 → 直接光为 0
```

- **NEE（Next Event Estimation，直接光重要性采样）**：旧方案靠漫反射光线
  随机命中太阳（概率仅 0.4%），命中就产生 60 倍亮度的白色火花噪点，
  方差巨大且收敛极慢
- 新方案确定性朝太阳盘采样，直接光**零方差**；软阴影由阴影光线被遮挡
  的概率渐变自然产生（盘上不同采样点遮挡状态不同）
- 每像素多采样（uSpp，默认 2）+ 显示端曝光校准 → 白噪点基本消失
- 太阳盘亮度（SUN_RADIANCE，镜面高光）与辐照度（SUN_IRRADIANCE，
  直接光）分离：高光要白、地面亮度要适中，两个量必须独立可调

### 3.7 路径追踪主循环

```glsl
vec3 radiance(Ray r) {
    vec3 color = 0, throughput = 1;
    for (i = 0; i < uMaxBounce; i++) {
        if (未命中) { color += throughput * skyColor(r.d); break; }
        if (被吸收) break;
        throughput *= atten;   // 能量随反弹递减
        r = scattered;         // 沿新方向继续
    }
    return color;
}
```

天空本身就是光源 → 直接光、间接光、软阴影全部由同一条递归光线自然产生。

## 四、关键函数速查

| 函数/概念 | 作用 |
|---|---|
| `glGenFramebuffers` + `glFramebufferTexture2D` | 创建渲染到纹理的帧缓冲 |
| `GL_RGBA32F` | 32 位浮点纹理（必须！8 位纹理装不下 HDR 累积和） |
| `glBlendFunc(GL_ONE, GL_ONE)` | 混合模式设为"相加" → 采样累加 |
| `rnd()` (PCG 哈希) | 无纹理伪随机数，像素坐标 + 帧号播种 |
| `randomUnitVector()` | 单位球面均匀随机方向 |
| `reflect()` / 自写折射 | GLSL 内置反射；折射按斯涅尔定律手写 |
| `smoothstep` | 太阳光盘柔和边缘 |
| ACES 色调映射 | HDR 亮度平滑压缩到 [0,1]（比 clamp 更自然） |
| `gl_VertexID` | 全屏三角形免顶点数据渲染 |
| `glfwSetScrollCallback` | 滚轮缩放相机 |

## 五、踩坑记录

| 现象 | 原因 | 解决 |
|---|---|---|
| 玻璃球边缘出现黑环 | 折射光线从表面起点再次与同一球相交 | 交点偏移 `EPS=1e-3`，且从内部击中时翻转法线 |
| 画面完全过曝发白 | 累积纹理用 8 位格式，HDR 溢出 | 改用 `GL_RGBA32F` 浮点纹理 |
| 每次移动相机画面全黑 | 累积和 ÷ 帧数，帧数归零除零 | 清空后先累加 1 帧再显示；除法用 `max(frameCount,1)` |
| 阴影边缘太硬 | 点光源无角半径 | 太阳改为有角半径的面积光，命中概率渐变 |
| 画面收敛慢、噪点多 | 漫反射均匀半球采样 | 余弦加权重要性采样，能量集中到法线方向 |
| 大量白噪点（火花闪烁） | 太阳强度 60 配合 0.4% 随机命中概率，命中即爆亮 | NEE 直接采样太阳 + 每帧多采样 + 极端亮度裁剪 |
| 加 NEE 后画面全白过曝 | 多反弹+强直射光让地面亮度 >14，超出 ACES 动态 | 地面反照率降到 RTIOW 水平，盘亮度/辐照度分离，统一曝光校准 |
| 球体垂直拉长成蛋形 | NDC 除以 res.y 后 x 已含 aspect，又乘了一次 aspect | NDC 统一除以 res.y，不再乘 aspect |
| 截图红蓝通道互换 | 24 位 BMP 像素顺序是 BGR，按 RGBA 直接写入 | 写像素时交换 0/2 通道：`bgr[dst+(2-c)]` |
| 小球埋入地面/藏在大球后 | 球心 y 小于半径、位置太靠边 | 球心 y = 半径让球底贴地 |
| 大球全挤在画面中部互相遮挡 | 相机在 (13,2,3) 看向原点，x 轴接近纵深方向，沿 x 排列的球前后重叠 | 仿 RTIOW 布局 (±4,1,0) 拉开 x 间距，必要时加 z 偏移错开屏幕投影 |
| 地面偶发亮斑、能量偏亮 | 太阳被双重计数：NEE 算过直接光，漫反射间接光线又能随机撞到天空里的太阳盘 | 漫反射弹出的光线命中天空时去掉太阳盘（`skyColor(d, withSun)`），镜面路径保留 |
| 玻璃球投全黑影子 | 阴影光线撞玻璃直接判为遮挡，真实玻璃会聚焦透光（焦散） | 阴影光线穿透玻璃，每面衰减 6%，影心留亮斑 |

## 六、延伸方向

1. **更多几何体** — 平面方程、三角形网格（BVH 加速求交）
2. **景深（DoF）** — 相机光圈随机偏移光线起点
3. **自发光物体 + 重要性采样** — 把发光球当光源直接采样，收敛更快
4. **法线贴图 / PBR 材质** — GGX 微表面模型替代 Schlick 近似
5. **硬件光追对比** — DXR/Vulkan RT 与软件光追的性能对比
6. **自适应采样** — 噪声大的区域多采样，简单区域少采样
