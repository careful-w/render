## 三、核心组件详解

### 3.1 着色器（Shader）

#### 顶点着色器（Vertex Shader）
```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
void main() {
    gl_Position = vec4(aPos.x, aPos.y, aPos.z, 1.0);
}
```
- 负责处理每个顶点的位置
- 此处直接透传，未做任何变换
- `location = 0` 对应 VAO 中 `glEnableVertexAttribArray(0)` 的槽位

#### 片段着色器（Fragment Shader）
```glsl
#version 330 core
out vec4 FragColor;
void main() {
    FragColor = vec4(1.0f, 0.5f, 0.2f, 1.0f);  // 橙色 RGB(255, 128, 51)
}
```
- 为光栅化后的每个像素（片段）设置颜色
- 所有片段统一为橙色

### 3.2 顶点数据与缓冲区对象

```cpp
float vertices[] = {
     0.5f,  0.5f, 0.0f,  // 右上  (索引0)
     0.5f, -0.5f, 0.0f,  // 右下  (索引1)
    -0.5f, -0.5f, 0.0f,  // 左下  (索引2)
    -0.5f,  0.5f, 0.0f   // 左上  (索引3)
};

unsigned int indices[] = {
    0, 1, 3,   // 三角形1：右上→右下→左上
    1, 2, 3    // 三角形2：右下→左下→左上
};
```

| 对象 | 全称 | 作用 |
|---|---|---|
| **VAO** | Vertex Array Object | 管理多个 VBO 的属性配置状态 |
| **VBO** | Vertex Buffer Object | 存储顶点数据（位置、法线、颜色等） |
| **EBO** | Element Buffer Object | 存储索引，避免重复顶点数据 |

### 3.3 `initVertexData` 函数流程

```
glGenVertexArrays / glGenBuffers    →  生成 VAO、VBO、EBO
glBindVertexArray(VAO)              →  绑定 VAO，后续操作状态均记录其中
glBindBuffer + glBufferData         →  上传顶点/索引数据到 GPU
glVertexAttribPointer               →  描述数据布局（每组3个float，对应位置）
glEnableVertexAttribArray(0)        →  启用 layout=0 的属性
glBindBuffer/glBindVertexArray(0)   →  解绑（好习惯）
```

### 3.4 编译链接着色器流程

```
glCreateShader  → 创建着色器对象（VERTEX / FRAGMENT）
glShaderSource  → 绑定 GLSL 源码
glCompileShader → 编译着色器
glCreateProgram → 创建着色器程序
glAttachShader  → 挂载着色器到程序
glLinkProgram   → 链接程序
glDeleteShader  → 删除已链接的着色器（不删除会内存泄漏）
```

错误检查：通过 `glGetShaderiv(..., GL_COMPILE_STATUS, ...)` 检查编译/链接状态，失败时用 `glGetShaderInfoLog` 获取日志。

## 四、主循环结构

```cpp
int main() {
    window = inte();           // ① 初始化 GLFW + GLAD  + 窗口
    initVertexData(...);       // ② 上传顶点/索引数据
    shaderProgram = createSimpleShader();  // ③ 编译链接着色器
    glUseProgram(shaderProgram);           // ④ 激活着色器程序

    while (!glfwWindowShouldClose(window)) {
        processInput(window);              // ⑤ 处理输入（ESC 退出）
        glClear(GL_COLOR_BUFFER_BIT);      // ⑥ 清屏
        glDrawElements(GL_TRIANGLES, 6, ...);  // ⑦ 绘制 6 个索引
        glfwSwapBuffers(window);           // ⑧ 交换缓冲（双缓冲）
        glfwPollEvents();                  // ⑨ 轮询事件
    }

    // 清理资源
    glDeleteVertexArrays / glDeleteBuffers / glDeleteProgram
    glfwTerminate();
}
```

### 关于双缓冲（Double Buffering）

- **前缓冲（Front Buffer）**：当前屏幕显示的内容
- **后缓冲（Back Buffer）**：正在绘制的帧

`glfwSwapBuffers()` 交换前后缓冲，避免画面撕裂。

## 五、关键函数速查

| 函数 | 作用 |
|---|---|
| `glfwInit()` | 初始化 GLFW |
| `glfwWindowHint(...)` | 设置窗口属性（OpenGL 版本、核心模式等） |
| `glfwCreateWindow(w, h, title, ...)` | 创建窗口 |

| `gladLoadGLLoader(...)` | 加载 OpenGL 函数指针 |
| `glViewport(x, y, w, h)` | 设置视口（窗口大小变化时回调） |
| `glClearColor(r, g, b, a)` | 设置清屏颜色 |
| `glClear(GL_COLOR_BUFFER_BIT)` | 清空颜色缓冲 |
| `glDrawElements(mode, count, type, indices)` | 按索引绘制 |
| `glfwSwapBuffers(window)` | 交换缓冲 |
| `glfwPollEvents()` | 处理事件队列 |

## 六、扩展方向

1. **Uniform 变量** — 向着色器传递动态数据（颜色、变换矩阵等）
2. **MVP 矩阵变换** — Model → View → Projection，实现 3D 渲染
3. **纹理贴图** — 用 `stb_image` 加载图片，替换纯色着色
4. **深度测试** — `glEnable(GL_DEPTH_TEST)` 处理遮挡关系
5. **光照模型** — Phong / Blinn-Phong 光照计算
6. **着色器文件化** — 从 `.vs` / `.fs` 文件读取 GLSL，告别内联字符串
