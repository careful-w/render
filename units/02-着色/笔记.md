## 二、Uniform 变量详解

### 2.1 什么是 Uniform

**Uniform** 是 CPU 向 GPU 着色器传递数据的方式，特点：

- **全局变量**：所有顶点/片段共享同一个值
- **只读**：着色器端不可修改
- **跨帧保持**：不手动更新则值不变
- **在 Shader Program 生命周期内有效**

### 2.2 数据类型对应

| GLSL 类型 | C/glm 类型 | 设置函数 |
|---|---|---|
| `float` | `GLfloat` | `glUniform1f(loc, v)` |
| `vec3` | `glm::vec3` | `glUniform3f(loc, x, y, z)` |
| `vec4` | `glm::vec4` | `glUniform4f(loc, x, y, z, w)` |
| `mat4` | `glm::mat4` | `glUniformMatrix4fv(loc, 1, GL_FALSE, ptr)` |
| `int` | `GLint` | `glUniform1i(loc, v)` |

### 2.3 使用流程

```
① GLSL 声明         uniform vec3 uColor;
② CPU 获取位置      GLint loc = glGetUniformLocation(program, "uColor");
③ CPU 设置值        glUniform3f(loc, r, g, b);
④ GPU 使用          FragColor = vec4(uColor, 1.0);
```

> ⚠️ **关键**：必须先 `glUseProgram(program)` 激活对应着色器程序，再调用 `glUniform*`。

## 三、两个 Shader Program 对比

### 3.1 三角形1 —— 动态着色

**顶点着色器** (`triangle.vert`)：接收 `voffset` uniform，实现键盘移动

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
uniform vec3 voffset;                          // ← 位置偏移
void main() {
    gl_Position = vec4(aPos.x + voffset.x,     // 在顶点上应用偏移
                       aPos.y + voffset.y,
                       aPos.z, 1.0);
}
```

**片段着色器** (`triangle.frag`)：接收 `uColor` uniform，实现动态变色

```glsl
#version 330 core
uniform vec3 uColor;                           // ← 颜色
out vec4 FragColor;
void main() {
    FragColor = vec4(uColor, 1.0);             // 输出 uniform 传入的颜色
}
```

### 3.2 三角形2 —— 固定着色（对照组）

**顶点着色器** (`triangle2.vert`)：无 uniform，位置固定

```glsl
#version 330 core
layout (location = 0) in vec3 aPos;
void main() {
    gl_Position = vec4(aPos.x, aPos.y, aPos.z, 1.0);
}
```

**片段着色器** (`triangle2.frag`)：直接硬编码红色

```glsl
#version 330 core
out vec4 FragColor;
void main() {
    FragColor = vec4(1.0, 0.0, 0.0, 1.0);
}
```

## 四、动态数据流

### 4.1 CPU → GPU 数据传输

```
                    每帧循环
                  ┌──────────┐
                  │ 更新 CPU  │
                  │ 颜色数组  │
                  │ 偏移向量  │
                  └────┬─────┘
                       │
                  glUniform3f()
                       │
                  ┌────▼─────┐
                  │  Uniform  │
                  │  缓冲区   │
                  └────┬─────┘
                       │
              ┌────────┼────────┐
         ┌────▼────┐       ┌────▼────┐
         │  Vertex  │       │ Fragment│
         │  Shader  │       │ Shader  │
         │ (voffset)│       │ (uColor) │
         └─────────┘       └─────────┘
```

### 4.2 颜色渐变算法

```cpp
float colors[] = {0.0f, 0.0f, 0.0f};

// 每帧递增，各自步长不同 → 产生彩虹渐变效果
colors[0] = (colors[0] + 0.005f) > 1.0f ? 0.0f : (colors[0] + 0.005f);  // R 增速
colors[1] = (colors[1] + 0.007f) > 1.0f ? 0.0f : (colors[1] + 0.007f);  // G 中速
colors[2] = (colors[2] + 0.009f) > 1.0f ? 0.0f : (colors[2] + 0.009f);  // B 慢速

// 当分量超过 1.0 时归零，形成循环
```

> 三个颜色分量以不同速率递增，RGB 比例不断变化 → 视觉上呈现彩虹渐变循环。

### 4.3 键盘移动原理

```cpp
// WASD → 修改 offset，着色器里应用到 gl_Position
if (glfwGetKey(window, GLFW_KEY_W) == GLFW_PRESS)  offset.x += 0.1f;  // 右移
if (glfwGetKey(window, GLFW_KEY_S) == GLFW_PRESS)  offset.x -= 0.1f;  // 左移
if (glfwGetKey(window, GLFW_KEY_A) == GLFW_PRESS)  offset.y += 0.1f;  // 上移
if (glfwGetKey(window, GLFW_KEY_D) == GLFW_PRESS)  offset.y -= 0.1f;  // 下移
```

> 注意：此处 W/S 映射到 X 轴（左右），A/D 映射到 Y 轴（上下），与常见游戏按键习惯略有不同。

## 五、Uniform 性能提示

### 5.1 位置获取只需一次

```cpp
// ✅ 正确：初始化时获取，避免重复查询
GLint colorLoc = glGetUniformLocation(shaderProgram, "uColor");  // 只调一次

while (...) {
    glUniform3f(colorLoc, r, g, b);  // 每帧只传数据
}
```

```cpp
// ❌ 错误：每帧查询位置（不必要的开销）
while (...) {
    GLint loc = glGetUniformLocation(shaderProgram, "uColor");  // 浪费性能
    glUniform3f(loc, r, g, b);
}
```

### 5.2 Uniform 数量限制

| 查询方式 | 典型值（现代 GPU） |
|---|---|
| `GL_MAX_VERTEX_UNIFORM_COMPONENTS` | 1024+ |
| `GL_MAX_FRAGMENT_UNIFORM_COMPONENTS` | 1024+ |

传大量数据时应该用 **Uniform Buffer Object (UBO)**，而非逐个 uniform。

## 六、新增关键函数速查

| 函数 | 作用 |
|---|---|
| `glGetUniformLocation(program, name)` | 获取 uniform 变量在着色器程序中的位置句柄 |
| `glUniform3f(location, x, y, z)` | 设置 `vec3` uniform 值 |
| `glUniform1f(location, v)` | 设置 `float` uniform 值 |
| `glUniformMatrix4fv(location, count, transpose, ptr)` | 设置 `mat4` uniform 矩阵 |

## 七、延伸方向

1. **Uniform Buffer Object (UBO)** — 批量传递 uniform 数据，适合多着色器共享
2. **顶点属性 vs Uniform** — 顶点属性是 per-vertex，Uniform 是全局共享
3. **MVP 矩阵变换** — 用 `mat4` uniform 传入 Model/View/Projection 矩阵
4. **纹理采样器** — `uniform sampler2D` 传递纹理数据
5. **光照参数** — 用 uniform 传入光源位置、颜色、强度等
