# 05 · 流体水（高度场波动方程 + 浮体动力学）

![效果](../../cmake-build-debug/fill_720.png)

> 启动时是空缸（浮体躺在缸底，见 start_empty.png），此图为开闸注水 12 秒注满后的画面。

## 1. 效果

- 启动时水缸是空的：5 个漂浮物躺在缸底，无水柱无水花
- 按空格开闸注水：水位以 0.10m/s 缓慢上涨（约 7 秒注满），浮体随水位上升自然浮起
- 水流冲击点压出凹坑并溅起白亮水花，波纹从落水点向四周同心扩散、碰玻璃壁反射
- 落水点固定（不游走）+ 双频脉动注水强度，波浪汹涌但无旋转感
- 关闭水龙头后：水位保持、不再产生新波纹，水面 3~4 秒内慢慢恢复平静
- 缸内 5 个漂浮物（木块、红块、黄球、青球、白球）随波起伏、被水流推着漂移
- 清水质感：水面颜色浅（深水区微青 (0.08,0.26,0.34)、浅水区接近无色），
  透明度高（基础 alpha 0.50），水底棋盘格和缸内物体清晰可见
- 波光粼粼：阳光高光叠极尖锐 glitter 分量（pow 400），波峰闪烁如真实水面
- 水面菲涅尔反射 + 高光 + 波陡处泡沫；玻璃缸边缘菲涅尔泛白
- 阴影贴图：浮体影子落在波纹水面/缸底，水管影子斜投地面（PCF 软阴影）
- 光线追踪反射：水面反射射线与浮体/缸壁/地面求交，倒影随波纹扭曲；
  反射命中点再向光源追射线做追踪软阴影
- 自然光：阳光暖白照受光面 + 天光冷蓝照暗面（无全局滤镜染色）
- 后处理：ACES 色调映射 + gamma 2.2 + 暗角，电影感统一色调

## 2. 核心原理

### 2.1 二维波动方程（高度场）

水面用 128×128 高度场 `h` 表示，每个格子存高度偏移和垂直速度 `v`：

```text
∇²h ≈ (h[左]+h[右]+h[上]+h[下]) / 4 - h[中]     离散拉普拉斯
v += c²·∇²h·dt        高处向低处加速（恢复力）
v *= DAMP           阻尼，波逐渐平息
h += v·dt
```

- **动态水位**：全局 `waterLevel`（启动 0 = 空缸），注水时每物理步 `+= FILL_RATE·dt`
  （0.10m/s，约 7 秒注满），上限 `MAX_WATER_Y = 0.72`；水面网格/水体方块/水流柱
  长度/浮力全部基于当前水位，水位低于 0.005 时不画水面和水体方块
- **波谷不穿底**：clamp 下限 `-min(0.13, waterLevel)`，浅水时波膜不会插到缸底下面
- **浮体缸底碰撞**：`y < WALL_T + size` 时停住（无水时躺在缸底，注水后自然浮起）

- **注水扰动**：每个物理步在冲击点以高斯权重对 `v` 施加负扰动（把水面往下压），
  强度带两个不同频率的正弦脉动，涟漪更自然
- **落水点固定**：冲击点不游走，波纹以落水点为中心同心扩散（参考真实水龙头）——
  游走会让凹坑绕圈，看起来像旋涡
- **双档阻尼**：注水时 0.9990（波浪汹涌持久）；关闭水龙头后切到 0.9940，
  衰减快约 6 倍，水面 3~4 秒恢复平静（半衰期 ≈ 2s）
- **关闭瞬间速度衰减**：关闭水龙头瞬间把 simV 全局乘 0.5，凹坑回弹不过冲——
  否则回弹环波 + 缸壁反射形成干涉驻波，看起来像漩涡
- **水花落水扰动**：只在注水时生效（pouring 条件），关闭后残存水花飞行不扰动水面
- **边界条件**：Neumann（边缘复制邻格）→ 波在玻璃壁上完全反射
- **均值守恒**：持续压水面会让平均水位漂移，每步把 h 的均值拉回 0
- **CFL 稳定性**：`K·dt² ≪ 4` 才不发散（K=2200，dt=1/120 → 0.15，安全）

### 2.2 水花粒子

注水时每个物理步从冲击点喷 2 颗小水珠（≈240 颗/秒，上限 400）：

- 初速：随机水平方向 0.35~1.2，垂直向上 1.0~2.7，只受重力做抛物线
- 落回水面时在落点激起一圈小涟漪（二次波纹），碰玻璃壁/超时则移除
- 渲染：小球网格**沿速度方向拉伸成椭球**（越快越长），随生命周期变淡；
  专属着色模式高环境光保持白亮（普通 Lambert 会像灰石子）

### 2.3 水流柱

上粗下细的圆台侧面网格（真实水流下落加速会变细），着色器里：

- 菲涅尔：中心几乎透明、边缘白亮 → 玻璃质感的水柱
- 纵向下冲流纹（双频叠加，只随高度滚动）——⚠ 不做绕壁螺旋，
  真实下落水流不会旋转，螺旋纹会像旋涡
- 长度每帧重算：从出水嘴到冲击点当前水面高度

### 2.4 浮体动力学

每个漂浮物做三种受力（均为半隐式欧拉积分，固定步长 1/120s）：

| 力 | 公式 | 效果 |
| --- | --- | --- |
| 弹簧浮力 | `vy += (水面高 - y)·k·dt` + 垂直阻尼 | 随波上下起伏 |
| 坡度推力 | `v -= ∇h·6·dt` | 顺波往低处滑 |
| 径向推流 | `v += (pos-冲击点)/dist²·dt` | 被注水流推开 |

⚠ 径向推流必须胜过坡度推力：冲击凹坑是持久低谷，坡度力会把浮体“吸”进水流里。

姿态：立方体的"上"轴用指数平滑跟随水面法线 `normalize(-∂h/∂x, 1, -∂h/∂z)`，
避免高频波动导致抖动；水平方向撞玻璃壁反弹（速度 × -0.35）。

### 2.5 阴影贴图

2048² 深度贴图，光源正交投影（±3.2m，近 0.5 远 12）：

- 阴影 pass 每帧重画：地面(cull back) → 水管/浮体(cull front 存背面深度防痤疮；
  浮体用 cull back 保证影子完整) → 水面（复用 water 着色器位移，加 `uShadowPass`
  提前返回只写深度）
- 浮体/水管的模型矩阵抽成 `floaterModel()`，两个 pass 共用保证一致
- 接收端：水面、缸底、地面、浮体采样 PCF 3×3；采样核逐像素随机旋转打散
  9 级灰度的等高线伪影
- 阴影贴图外区域（CLAMP_TO_BORDER 深度 1.0）视为被照亮

⚠ LIGHT_DIR 约定是“指向光源”，阴影相机应放在 `target + LIGHT_DIR×距离`；
写反成减法会把光源埋到地面以下，地面自阴影出同心波纹。

### 2.6 后处理

场景渲完再渲一个全屏三角形：

- Narkowicz ACES 近似色调映射（高光柔和滚降）× 1.02 曝光
- gamma 2.2；轻微暗角（屏幕半径 0.1 系数，把视线聚到水缸）
- 快照从 postFBO 读像素（截到后处理后的画面）

### 2.7 水面光线追踪反射

水面片段着色器里直接做反射射线求交（光栅化管线内的局部光线追踪）：

- 反射方向 `reflect(-V, N)` 依次与 5 个浮体（球求交，立方体用 1.6 倍外接球
  近似）、缸内壁（±INNER_X/±INNER_Z 平面）、地面 y=0 求交，取最近命中
- 命中浮体 → 材质色 × 暖光 Lambert + 高光，且从命中点向光源再追一条射线，
  被其他浮体挡住则减半（追踪软阴影）
- 命中缸壁 → 亮边色；命中地面 → 棋盘格；未命中 → 天空渐变（天顶蓝、地平线暖白）
- 混合权重 `clamp(fresnel×1.55)`，浮体数据（位置/颜色/尺寸/形状）每帧经
  `uFloaterPos[5]` / `uFloaterParam[5]` uniform 数组上传，与主渲染完全同步
- 阴影 pass 提前返回（uShadowPass==1），不重复计算

### 2.8 自然光（阳光暖白 + 天光冷蓝）

不靠全局滤镜调色，而是模拟自然光的双色特性：

- 阳光 `(1.0, 0.93, 0.82)` 暖白：只作用于受光面（diffuse 项）和高光
- 天光 `(0.36, 0.38, 0.42)` 冷蓝灰：作用于环境/暗面——阴影处自然偏冷
- 光照公式 `base × (AMBIENT + LIGHT_COL×0.65×diff)`：亮面暖、暗面冷
- ⚠ 不要在 post 里叠全局暖色偏移——整幅画面染色会像滤镜，不自然；
  曝光 1.02 即可，不用高曝光提亮

### 2.9 清水质感

参考真实清水照片调色，水要“透”不要“实”：

- 深浅水色随波高变化：深水区 `(0.08, 0.26, 0.34)` 微青、浅水区 `(0.34, 0.56, 0.58)`
  接近无色——不要用深蓝绿，否则像凝胶
- 水面基础 alpha 0.50（原 0.62），fresnel×0.40 + foam×0.3 叠加，水底清晰可见
- 高光三层：宽幅柔光 pow 12 × 0.15（整体反光）+ 锐利高光 pow 120 + 波光
  glitter pow 400 × 1.3（波峰闪烁），全部乘阳光色并乘阴影因子
- 水体方块同步调浅：色 (0.28, 0.50, 0.56)、alpha 0.15（原 0.28 太实）
- 水流柱中心基础 alpha 0.22（几乎全透明），只靠菲涅尔边缘 + 高光塑形
- 水花环境光 0.85 + 锐利高光 pow 300，白亮水珠感

### 2.10 渲染

- 高度场每帧 `glTexSubImage2D` 上传 R32F 纹理；水面网格顶点着色器采样位移，
  片段着色器中央差分重建法线（纹素间距要换算成世界距离）
- **透明排序**（关深度写入，手动后到前）：
  玻璃背面(cull front) → 水体方块 → 水流柱 → 水面 → 水花 → 玻璃正面(cull back)
- 渲染链：阴影贴图 pass → 场景 FBO → 后处理 FBO → blit 上屏（快照模式也可靠）

## 3. 踩坑记录

| 坑 | 原因 | 解决 |
| --- | --- | --- |
| 缸下半截像空的 | 只画了水面一层，水下没有颜色 | 补一个半透明蓝色水体方块（缸底到水面下 5cm） |
| 波动发散爆炸 | 波速太大违反 CFL 条件 | 保证 K·dt² ≪ 4，外加高度 clamp ±0.13 |
| 浮体被吸进水流 | 冲击凹坑是持久低谷，坡度力把浮体拉进去 | 加大径向推流（0.16→0.5）、削弱坡度力（8→6） |
| 水花像灰色石子 | Lambert 光照下水珠背光面太暗 | 专属着色模式：高环境光 0.8 + 强高光 |
| 水花圆球形假 | 静止圆球没有运动感 | 沿速度方向拉伸成椭球 + 随生命周期变淡 |
| 水流柱像理发店条纹柱 | 方盒网格 + 横条纹，无菲涅尔 | 锥形圆管 + 中心透明/边缘白亮 + 螺旋流纹 |
| 平均水位越来越低 | 冲击点持续对 v 施加负扰动 | 每步减去高度场均值 |
| 浮体抖动 | 直接用瞬时水面法线定姿态 | 法线做指数平滑（1-exp(-5dt)） |
| 透过水面看不到后壁 | 透明物写深度互相遮挡 | 透明阶段 glDepthMask(FALSE) + 手动排序 |
| 非均匀缩放法线歪 | 立方体缩放成墙/地面后法线没修正 | 用 transpose(inverse(mat3(model))) 变换法线 |
| 地面同心波纹 | 光源位置写成 `target - LIGHT_DIR×d`（LIGHT_DIR 指向光源，
  光源被埋到地面以下，地面自阴影） | 改为 `target + LIGHT_DIR×d` |
| 阴影边缘等高线 | PCF 3×3 只有 9 个灰度级，软阴影边界出现分层 | 采样核逐像素随机旋转（哈希角）打散 |
| 新着色器没进构建 | CMake glob 不自动检测新文件 | 新增着色器后重新跑 cmake 配置 |
| 光线煞白刺眼 | 高光/菲涅尔全用纯白 (1,1,1)，曝光 1.12 过高 | 暖白光源统一高光，曝光降 1.02 |
| 整体画面像蒙了暖色滤镜 | 后处理全局乘暖色偏移，自然光不该整幅染色 | 删掉全局偏移，改为阳光暖白×受光面 + 天光冷蓝×暗面 |
| 水流柱螺旋纹像旋涡 | 流纹用绕壁角度做螺旋，真实下落水流不旋转 | 去掉角度项，只留纵向双频流纹 |
| 水面倒影不明显 | 反射混合只乘 fresnel×1.25，垂直视角下菲涅尔值低 | 提到 ×1.45；验证时先临时输出纯反射色确认追踪命中 |
| 关闭水龙头后水面仍翻腾 | 阻尼写死 0.9990（半衰期约 7s），衰减太慢 | 双档阻尼：注水 0.9990 / 关闭 0.9940（半衰期 2s），4 秒恢复平静 |
| 关闭后水花落水还在搅动 | 残存水花 (≤400) 落水时 disturb 激起新涟漪 | 加 pouring 条件，关闭后水花只飞不扰动 |
| 关闭后凹坑回弹像漩涡 | 回弹环波 + 缸壁反射形成干涉驻波，振幅大 | 关闭瞬间 simV 全局乘 0.5，回弹温和 |
| 落水点附近像旋涡 | 冲击点沿利萨茹轨迹绕圈游走，凹坑跟着转 | 落水点固定，波纹同心扩散（参考真实水龙头落水照片） |
| 空缸时波膜穿缸底 | 波高 clamp 只限 ±0.13，浅水时波谷低于缸底 | clamp 下限改为 -min(0.13, waterLevel)，波谷最多到 y=0 |
| 浮体悬空不下沉 | 无水时没有缸底约束，弹簧浮力拉不住 | 加缸底碰撞 y ≥ WALL_T+size，无水时躺在缸底 |
| 水像凝胶不透明 | 深蓝绿色 (0.06,0.16,0.24) + alpha 0.62，水下什么都看不清 | 调浅调透：深水微青、浅水近无色、alpha 0.50、水体方块 alpha 0.15 |
| 水面反光平糊 | 只有单一 pow 120 高光，波峰不亮 | 加三层高光：柔光 + 锐利高光 + 波光 glitter pow 400 |
